# Security Policy

## Supported versions

Security fixes are applied to the latest release on `master`.

## Reporting a vulnerability

Please report suspected vulnerabilities privately by opening a **GitHub security advisory** for this repository.

If you cannot use GitHub advisories, open a private report through the repository maintainers and include:

- A clear description of the issue
- Reproduction steps or proof of concept
- Expected impact and affected versions

Please do not publicly disclose security issues until a fix is available.

## Response expectations

Maintainers will acknowledge reports as quickly as possible, validate impact, and coordinate a fix/release when confirmed.
